# CEUTONOMO design direction

## Review

The dashboard establishes a useful hierarchy, but small supporting text, inconsistent controls and crowded header actions weaken its finish. Dark mode retains several light-mode colors. Tablet navigation needs accessible names when labels are hidden. The cookie acceptance button has white text on a white background because of selector specificity.

## Implementation instructions

1. Use a restrained financial editorial style: warm neutral canvas, ink navy navigation and teal accents.
2. Align all major panels to one content width; keep header actions together and stop stretching them vertically.
3. Use larger supporting text, generous line height and tabular figures. Reserve oversized numbers for the principal result.
4. Standardize cards at 16px corners and controls at a 44px minimum height. Use subtle borders and low shadows.
5. Give interactive elements visible keyboard focus. Avoid hover movement on informational cards and honor reduced motion.
6. Keep estimated aid visually conditional. Preserve all tax caveats and calculation behavior.
7. Provide explicit dark surfaces and readable accent colors, including form labels, warning copy and cookie buttons.
8. Check desktop and mobile in both themes, including overflow and browser errors.

## Remaining product work outside this visual pass

Complete English translations and unfinished navigation destinations separately. A visual refresh does not make these features complete.
