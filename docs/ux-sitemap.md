## Primary Phase 1 journey

1. User opens a seeded Spanish demo with the €300/day software consultant profile.
2. User edits rate, days, months, expense deductibility, residence/activity facts, and first-time autónomo status.
3. Eligibility is evaluated with visible reasons and missing facts.
4. The simulator shows revenue, costs, contributions, ordinary tax status, Ceuta adjustments, and net values without mixing categories.
5. “Cómo se ha calculado” expands every line and links to official sources.
6. Warnings identify actions that need verification before alta, investment, or application.

## First viewport

A working simulator/dashboard—not a marketing hero—shows:

- editable revenue assumptions;
- net-income and cost summary;
- rule verification status;
- the most urgent warning or missing fact;
- direct continuation into eligibility questions.

## Visual thesis

“Mediterranean fiscal clarity”: deep navy and mineral blue for structure, restrained sea-green only for verified or potential savings, amber for verification, and red only for eligibility failures. Tabular numerals, strong Spanish typography, generous whitespace, thin rule lines, and a distinctive vertical calculation ledger replace generic admin-card grids.

Desktop uses a compact sidebar and a wide working ledger. Mobile uses compact bottom navigation and stacked inputs/results. Both themes meet readable contrast and preserve meaning without color alone.

## Required states

- incomplete profile with missing-fact prompts;
- calculating/loading;
- verified result;
- potentially eligible result;
- professional verification required;
- no active grant windows;
- source unavailable/stale;
- recoverable validation error;
- saved/unsaved scenario state when persistence is introduced.
